
# 📊 Super Store Profit Summary Dashboard

## 🔹 Project Overview
This project is an interactive business intelligence dashboard created using Power BI to analyze sales, profit, orders, and customer trends from the Super Store dataset.

The dashboard helps in understanding:
- Sales performance
- Profit trends
- Category-wise analysis
- Regional insights
- Business growth opportunities

---

# 🛠 Tools & Technologies Used
- Power BI
- SQL
- Python
- Excel / CSV
